# Question 2 Design Explanation Template Method Pattern

The Template Method pattern is implemented in the abstract `Report` class, where `generateReport()` serves as the template method. `generateReport()` is declared `final`, meaning subclasses cannot alter the overall algorithm — it always calls `loadData()`, then prints the header section and calls `formatHeader()`, then the body section and `formatBody()`, then the footer section and `formatFooter()`, in that fixed order. The four step methods (`loadData`, `formatHeader`, `formatBody`, `formatFooter`) are declared `abstract`, requiring each concrete subclass — `StudentReport` and `CourseReport` — to provide its own implementation. The `Driver` uses a `List<Report>` and calls `generateReport()` polymorphically on each element, demonstrating that the caller never needs to know the concrete type of the report being generated.
